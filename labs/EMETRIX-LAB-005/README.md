# EMETRIX-LAB-005 — Configure a Security Appliance

> **Network Security • pfSense • DNS Configuration • WAN Configuration • Gateway Management**

## 📋 Business Scenario
A network security appliance provides a critical enforcement point between network segments and external connectivity. Incorrect DNS, WAN, or gateway configuration can affect availability, routing, name resolution, and downstream security controls.

## 🎯 Lab Objective
Configure and validate core security-appliance network parameters in a controlled laboratory environment.

## ⚠️ Threat Addressed
Incorrect or insecure appliance configuration can introduce connectivity failures, routing problems, misdirected traffic, and weaknesses at the network boundary.

## 🛡️ Security Controls Implemented
- Security-appliance baseline
- DNS configuration
- WAN interface configuration
- Default gateway management
- Configuration validation

## 🛠️ Implementation Walkthrough
The laboratory was completed in a controlled pfSense environment. The public documentation records the security-relevant configuration outcome without reproducing proprietary instructions or sensitive identifiers.

## 🔍 Security Analysis
DNS, WAN addressing, and gateway settings influence how traffic is resolved and routed at the network boundary. They should therefore be treated as part of the security baseline.

## 📊 Business Impact
A correctly configured appliance provides a predictable foundation for firewall rules, segmentation, monitoring, and secure connectivity.

## 🏢 Enterprise Applications
- Perimeter firewall deployment
- Branch-office security
- Network segmentation
- Secure internet gateways
- Network-security baseline management

## 🧠 Skills Demonstrated
pfSense administration • network security • DNS configuration • WAN configuration • gateway management • validation

## 📝 Professional Reflection
The laboratory reinforced the importance of establishing a controlled network-security baseline before implementing higher-level firewall and monitoring policies.
