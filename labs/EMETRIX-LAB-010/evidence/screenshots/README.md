# LAB-010 Evidence — Perform System Configuration Gap Analysis

This evidence checklist will be finalized against the actual laboratory execution. Do not fabricate screenshots or findings.

## Capture These Evidence Categories

1. `01-system-assessment-environment.png` — controlled assessment environment and target system context.
2. `02-baseline-configuration-evidence.png` — expected security baseline or control criteria used for comparison.
3. `03-observed-configuration-evidence.png` — actual observed configuration state relevant to the assessment.
4. `04-configuration-gap-evidence.png` — clear evidence of each material deviation identified.
5. `05-risk-validation-evidence.png` — supporting validation that demonstrates the security significance of the identified gap.
6. `06-remediation-validation.png` — remediation or corrected configuration, only if the lab includes remediation.
7. `07-lab-validation-result.png` — final laboratory result, if provided by the exercise.

## Sanitization

Never publish credentials, secrets, production configuration, real organizational identifiers, internal topology, or unnecessary personal data. Each finding must be supported by the actual evidence captured during the authorized laboratory.
