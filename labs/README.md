## Evidence Standard

Each completed laboratory should connect four proof layers:

**Technical Report → Sanitized Evidence → Validation Result → Public Walkthrough**

Screenshots are supporting evidence, not a substitute for technical analysis. Evidence must be captured from authorized, controlled environments and sanitized before publication.

## Documentation Standard

Each lab follows the established EMETRIX professional structure:

1. Lab Overview
2. Executive Summary
3. Security Objective
4. Lab Requirements
5. Environment
6. Architecture
7. Security Controls Implemented
8. Implementation
9. Evidence
10. Findings & Security Analysis
11. Risk Considerations
12. Validation
13. Lessons Learned
14. Skills Demonstrated
15. References & Attribution
16. EMETRIX Labs Methodology
17. Lab Status
18. Media

## Branding Standard

Every laboratory README uses the official EMETRIX Tech master logo from `assets/branding/emetrix-tech-logo.png`. The logo is a brand asset and is not replaced by generated artwork.

## Publication Standard

YouTube recordings are supporting media, not a replacement for technical documentation. Video URLs are added only when their mapping to a specific lab is verified.

The reports document the author's practical execution, security reasoning, evidence, and outcomes rather than reproducing proprietary training instructions.
