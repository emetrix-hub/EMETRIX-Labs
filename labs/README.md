## Documentation Standard

Each laboratory is documented around:

- Objective
- Environment
- Security concepts
- Tools and technologies
- Methodology
- Implementation or investigation
- Evidence
- Findings
- Risk analysis
- Remediation
- Validation
- Lessons learned
- Skills demonstrated
- References
- Media and publication links

> Training material and proprietary content are not reproduced as portfolio content. The repository focuses on original execution, analysis, evidence, documentation and lessons learned.
