## Publication Standard

Every completed laboratory should connect four proof layers:

**Technical Report → Sanitized Evidence → Validation Result → Public Walkthrough**

YouTube recordings are treated as supporting media, not as a replacement for technical documentation. Video URLs are added only when their lab mapping has been verified.

The reports document the author's practical execution, security reasoning, evidence and outcomes rather than reproducing proprietary training instructions.
