# EMETRIX-LAB-008 — Configure Account Password Policies

> **Identity Security • Authentication • Password Policy • Windows Security**

## 📋 Business Scenario
An organization needs consistent password controls to reduce weak-credential risk and establish a defined authentication baseline.

## 🎯 Lab Objective
Configure and validate account password-policy controls in a controlled Windows security environment.

## ⚠️ Threat Addressed
Weak, predictable, reused, or poorly managed passwords that can facilitate unauthorized account access.

## 🛡️ Security Controls Implemented
- Password-policy enforcement
- Password complexity requirements
- Password-length controls
- Password-age controls
- Account-lockout controls
- Authentication baseline management

## 🛠️ Implementation Walkthrough
The laboratory was completed in a controlled training environment. The public documentation records the security configuration and outcome without exposing account credentials or proprietary instructions.

## 🔍 Security Analysis
Password policy is one layer of identity security. Modern identity programs should also incorporate MFA, breached-password detection, secure recovery, monitoring, and risk-based authentication.

## 📊 Business Impact
A consistent authentication baseline reduces avoidable credential risk and provides a defined policy against which accounts can be assessed.

## 🏢 Enterprise Applications
- Active Directory environments
- Windows domain security
- Identity and access management
- Enterprise authentication baselines

## 🧠 Skills Demonstrated
Windows security administration • password-policy configuration • identity security • authentication controls • baseline validation

## 📝 Professional Reflection
The laboratory reinforced that authentication security combines policy, technical enforcement, monitoring, and broader identity controls.

## 📚 References & Attribution
