# EMETRIX-LAB-001 — Implement Physical Security Countermeasures

## Executive Summary

This laboratory exercise focused on implementing physical security countermeasures designed to protect a restricted networking environment.

The exercise demonstrated how multiple physical security controls can be combined to reduce unauthorized physical access and improve visibility around a sensitive infrastructure area.

The implemented controls included:

- Smart card access readers
- IP security cameras
- Restricted access signage
- Visitor logging

The laboratory was completed successfully with a score of 4/4 (100%).

---

## Lab Objective

The objective of this laboratory was to implement physical security controls around a building entrance and a restricted networking closet.

The exercise focused on applying layered physical security measures to:

- Control physical access
- Monitor sensitive areas
- Clearly identify restricted areas
- Maintain visitor accountability

---

## Security Concepts

### Physical Access Control

Smart card readers were used as an access-control mechanism at designated entry points.

The exercise required access readers at:

- The building's front entrance
- The networking closet entrance

This demonstrates the use of electronic authentication to restrict physical access.

### Video Surveillance

IP security cameras were deployed to provide monitoring of the networking closet environment.

The exercise included:

- A camera positioned inside the networking closet
- A camera positioned outside the networking closet

Video surveillance provides an additional detective control by increasing visibility around sensitive infrastructure.

### Security Signage

A Restricted Access sign was placed on the networking closet door.

This provides a clear directive that access to the area is restricted.

### Visitor Management

A visitor log was placed at the lobby desk.

This supports visitor accountability by providing a mechanism for recording visitors entering the environment.

## Findings

The laboratory demonstrates that physical security should use multiple complementary controls rather than relying on a single mechanism.

The implemented control set provides several layers:

**Preventive**

- Smart card readers
- Restricted access signage

**Detective**

- IP security cameras

**Administrative / Accountability**

- Visitor logging

The combination provides a layered approach to protecting a sensitive networking environment.

---

## Security Analysis

A networking closet can contain infrastructure that supports critical organizational services.

Unauthorized physical access could potentially provide an attacker with opportunities to:

- Access network equipment
- Tamper with infrastructure
- Disconnect equipment
- Introduce unauthorized devices
- Obtain information from physical systems

The implemented controls reduce these risks by combining access restriction, surveillance, signage and visitor accountability.

---

## Risk Reduction

| Threat | Relevant Control | Risk Reduction |
|---|---|---|
| Unauthorized physical entry | Smart card reader | Restricts access |
| Unauthorized access to networking closet | Smart card reader | Adds controlled authentication |
| Undetected physical activity | IP cameras | Improves visibility |
| Accidental/unauthorized entry | Restricted Access sign | Communicates restrictions |
| Untracked visitors | Visitor log | Improves accountability |
