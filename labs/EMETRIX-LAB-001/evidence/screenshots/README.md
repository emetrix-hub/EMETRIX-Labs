# Evidence

This directory contains sanitized evidence captured during the EMETRIX-LAB-001 laboratory.

## Evidence Standards

Evidence is collected from the controlled training environment and is used to demonstrate the implementation, observation and validation of the security controls examined during the laboratory.

Before publication, evidence must be reviewed for:

- Credentials
- Passwords
- API keys or tokens
- Personal information
- Private organizational information
- Sensitive network information
- Proprietary training material

Only relevant and appropriately sanitized evidence should be published.

## Evidence Categories

Evidence may include:

- Environment overview
- Security-control configuration
- Access-control examples
- Monitoring examples
- Visitor-management examples
- Validation results
