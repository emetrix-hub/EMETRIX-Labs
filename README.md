EMETRIX Labs is the hands-on cybersecurity engineering portfolio of **EMETRIX Tech**. It documents controlled laboratory work, security investigations, defensive configuration, technical research, evidence, validation, and lessons learned.

## Scope

The repository is designed as a professional technical portfolio rather than a collection of copied course instructions. Lab reports focus on the work performed, security reasoning, evidence, findings, remediation considerations, and validation results.

## Evidence Standard

Each completed laboratory should connect four proof layers:

**Technical Report → Sanitized Evidence → Validation Result → Public Walkthrough**

Screenshots are supporting evidence, not a substitute for technical analysis. Evidence must be captured from authorized, controlled environments and sanitized before publication.

## Security & Safety

Do not publish credentials, private keys, authentication tokens, session cookies, production identifiers, unnecessary personal data, workplace/client information, or proprietary course instructions. See `SECURITY.md` for the repository publication rules.

## Source Attribution

Some labs are based on commercial training exercises. EMETRIX Labs does **not** reproduce proprietary lab instructions. Source material is used as learning context; the portfolio records the author's practical execution, observations, analysis, evidence, validation, and lessons learned.

## Media

Selected laboratory work is recorded for EMETRIX Tech educational content across YouTube, LinkedIn, TikTok, Instagram, and other channels. Video URLs are added to individual lab reports only after the recording-to-lab mapping is verified.
