# Security Policy

## Scope

EMETRIX Labs is a public educational portfolio. Laboratory systems are isolated and authorized for testing.

## Publication Rules

Never commit:

- passwords or authentication secrets
- API keys, tokens, certificates, private keys, or session cookies
- personal data that is not necessary for the learning objective
- production IP addresses, hostnames, MAC addresses, or internal topology
- photographs or information from client/workplace environments
- proprietary course content or copied lab instructions

## Evidence Handling

Sanitize screenshots and logs before publication. Preserve enough technical context to demonstrate the finding without exposing unnecessary identifiers.

## Responsible Testing

All offensive or investigative activity represented in this repository is intended for controlled, authorized environments only. Do not scan, enumerate, intercept, or test systems without permission.

## Reporting

If a repository issue could expose sensitive information, do not publish the sensitive data in the issue. Contact the maintainer privately through an appropriate channel.
