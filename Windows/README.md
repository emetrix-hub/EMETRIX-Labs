# Windows Administration

Welcome to the **Windows Administration** section of EMETRIX Labs.

This section documents practical laboratories focused on Windows administration, Active Directory, Microsoft security technologies, system hardening, and enterprise infrastructure management.

---

## Overview

Topics covered include:

- Active Directory
- Group Policy (GPO)
- Windows Server
- DNS
- DHCP
- Certificate Services (AD CS)
- Windows Event Viewer
- PowerShell
- BitLocker
- Windows Defender
- Windows Defender Application Control (WDAC)
- Credential Guard
- Local Security Authority (LSA)
- Windows Security Baselines
- Microsoft 365 Administration
