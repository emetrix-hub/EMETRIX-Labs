# Contributing to EMETRIX Labs

EMETRIX Labs is maintained as a professional cybersecurity portfolio.

## Lab Documentation

Use the permanent ID format `EMETRIX-LAB-XXX` and the standard 18-section report structure. Document what was actually performed and observed; do not invent results.

## Evidence

Use sanitized screenshots and logs. Never commit credentials, secrets, production data, or proprietary training instructions.

## Naming

Prefer lowercase, descriptive, hyphen-separated filenames for new technical assets.

## Quality Gate

Before publication, verify:

- Markdown renders correctly.
- Relative image links work.
- Evidence matches the documented activity.
- Sensitive identifiers are sanitized.
- Sources and attribution are clear.
- No proprietary instructions are reproduced.
