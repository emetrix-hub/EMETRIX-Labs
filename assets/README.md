# Assets

Welcome to the **Assets** directory of EMETRIX Labs.

This directory stores shared resources used throughout the repository.

The assets directory may contain:

- Repository Banner
- EMETRIX Tech Logo
- Architecture Diagrams
- Network Topology Diagrams
- Screenshots
- Icons
- Flowcharts
- Images
- PDFs
- Documentation Resources

Resources contained in this directory are shared across multiple laboratories, documentation pages, and technical case studies.
