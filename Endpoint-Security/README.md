# Endpoint Security

Welcome to the **Endpoint Security** section of EMETRIX Labs.

This section documents practical laboratories focused on securing Windows and Linux endpoints, endpoint detection, hardening, and defensive security controls.

## Overview

Topics covered include:

- Microsoft Defender
- Windows Defender Application Control (WDAC)
- BitLocker
- Endpoint Detection and Response (EDR)
- Windows Security
- Linux Endpoint Hardening
- Group Policy Security
- Device Control
- Credential Protection
- Attack Surface Reduction
- Endpoint Monitoring

## Repository Structure

Each laboratory includes:

- Executive Summary
- Business Context
- Technical Objective
- Lab Environment
- Technologies Used
- Configuration or Investigation
- Results
- Lessons Learned
- Skills Demonstrated
- Related Technologies

## Status

This documentation is continuously updated with new endpoint security laboratories and research.

## Disclaimer

The projects in this section are independent technical laboratories, proof-of-concept implementations, and research exercises designed to demonstrate practical endpoint security knowledge. They are not commercial client engagements.
